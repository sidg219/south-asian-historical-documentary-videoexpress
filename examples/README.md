# Example episode packets

The standard output is one detailed Markdown document for a 4–6 minute episode. It must place every scene-by-scene image prompt before the corresponding VideoExpress image-to-multishot prompt.

Each episode packet should contain:

1. `brief.md` — question, region, date range, audience and format.
2. `sources.md` — source list with notes and access dates.
3. `claim-ledger.md` — narration claims, evidence and confidence.
4. `narration.md` — final voiceover with scene IDs.
5. `storyboard.md` — visual plan and reconstruction labels.
6. `prompts.md` — image and video prompts using the World Lock.
7. `edit-checklist.md` — continuity, captions, credits and export.

The first suggested pilot is “A Morning at the Port of Muziris,” focused on trade, commodities, languages and the limits of what archaeology can tell us about daily life. Treat that as a proposal, not a factual source.
